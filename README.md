# KeyLib

Windows 本地密码管理器。所有账号保存在同一列表。桌面和浏览器共用本地加密密码库与 **Alt+C** 快捷键。

## 开始使用

1. 将 Windows x64 发行包完整解压到固定文件夹，双击 **KeyLib.exe**。同目录的 **libsodium.dll** 用于加密。
2. 首次打开时创建主密码，之后用它解锁。请妥善保管主密码，忘记后无法恢复。新密码库位于 %LOCALAPPDATA%\KeyLib\vault.softvault。安装过旧版时，KeyLib 会直接读取原有密码库。
3. 切到目标桌面应用，点击用户名框或密码框，按 **Alt+C** 唤出小窗。若其他程序已注册该组合，主窗口会显示占用状态。
4. 新建或快速保存账号时，可以在备注填应用名，例如「Riot Client」。KeyLib 从开始菜单和 Windows 的安装注册信息查找应用，备注匹配到唯一应用时会自动关联。打开该应用后，解锁状态下会为该进程提示一次候选账号。点「选择应用」可搜索并手动指定，也可以保持无关联。已有的手动关联优先。
5. 快捷小窗的「随机密码」默认生成 24 字符，能重新生成、带入保存，或填写当前聚焦且可确认的密码框。主界面的生成器允许调整长度和是否包含符号。

拖动主窗口顶部的标题栏可移动窗口。点关闭按钮会把窗口隐藏到 Windows 右下角的通知区域。点击 KeyLib 托盘图标即可恢复；图标是否收在小箭头内由 Windows 的托盘设置决定。右键托盘图标或打开「设置」可退出程序。锁屏、休眠或电脑闲置 5 分钟时自动锁库。

小窗里点「填写」可选某个账号，按回车填写列表中的第一个账号。按 Esc、点击小窗外或切换前台窗口都会关闭小窗。回车用于确认填写，登录仍由你在目标应用里完成。若切换发生在两个字段之间，已经写入的用户名可能留在原窗口。

### 浏览器扩展

1. 在 KeyLib 主窗口解锁，打开「设置」，点「启用本机连接」。这一步注册当前 Windows 用户的 Native Messaging 主机。
2. 在 Chrome 的 chrome://extensions 或 Edge 的 edge://extensions 打开扩展管理。开启「开发者模式」后，点「加载已解压的扩展程序」，选择发行包内的 **extension** 文件夹。
3. 在 HTTPS 登录页按 **Alt+C**，或点击工具栏中的 KeyLib 图标。小窗可以匹配账号、填写、生成密码和快速保存。「读取当前表单」需要你主动点击，保存前可核对两个字段。
4. 如果浏览器保留了旧热键或未完成分配，在扩展快捷键页面将 KeyLib 设为 **Alt+C**。启用本机连接后，KeyLib 会在 Chrome 或 Edge 位于前台时把该组合交给扩展，离开浏览器后由桌面小窗接收。

扩展按完整 HTTPS 来源（协议、主机和端口）匹配，并把填写绑定到打开小窗时的浏览器文档。首版针对顶层页面的常规表单。跨域 iframe、多步登录、自绘控件和验证码需要在原应用中处理。

### 加密备份

- **文件方式**。在「加密备份」点「导出加密文件」。另一台设备解锁后点「导入并合并」，选择文件并输入**源密码库的主密码**。接收端已有条目会保留。
- **局域网直传**。让两台电脑处于可互通的同一 IPv4 局域网。接收端在「加密备份」选择网卡地址、点「接收备份」并选保存位置。将一次性配对码交给发送端，在发送端粘贴并点「发送备份」。收到后可以导入合并。配对码一次有效，等待连接的时限为 2 分钟。防火墙或网络隔离阻断连接时，可以使用加密文件方式。

## 安全范围

- 密码库用 libsodium 的 Argon2id v1.3 派生密钥（3 次、64 MiB、随机盐），并使用 XChaCha20-Poly1305 认证加密。账号、密码、网址、应用绑定和备注全部加密落盘。
- 局域网传输在密码库密文外再做一次认证加密，使用配对码中的 256 位随机密钥，并验证接收端回执。接收监听只在用户主动开启时建立。日常操作无需公网、账号、遥测或云服务。
- 桌面匹配核对应用路径和 SHA-256 指纹。未明确关联的条目按备注匹配系统识别到的应用，结果有歧义时保持无关联。填写前核对实际字段和前台窗口。双字段填写适用于用户名和密码按 Tab 相邻，并且暴露可访问控件的应用。
- 浏览器通道使用限制在当前 Windows 用户的本机命名管道。软件信任被填入的应用、网页和当前 Windows 会话。会话已被恶意软件控制时，解锁中使用的账密仍可能泄露。本项目尚未经过独立安全审计。

## 从源码构建

需要 Windows x64、.NET Framework 4.8（或 4.8.1）和 PowerShell。在源码根目录运行：

    powershell -NoProfile -File .\Build.ps1

产物在 bin。源码包包含用于本次构建的 libsodium 1.0.20 Windows x64 依赖及其 ISC 许可证。项目源码采用 MIT。浏览器扩展的公钥用于固定开发版 ID。

密码库格式版本为 SVLT0001。构建无需在线下载依赖。
